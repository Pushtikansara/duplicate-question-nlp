# Explainability Engine -- ARES Phase 8 RTEE

## Overview

`ExplainabilityEngine` produces three complementary forms of explanation for every prediction: a human-readable summary, a technical diagnostic string, and a per-module contribution breakdown. It is invoked once per `reflect()` cycle after all auditors have run.

## Output Structure

```python
{
    "human_readable": str,
    "technical": str,
    "module_contributions": dict[str, float],
}
```

## Human-Readable Explanation

Generated by `_generate_human_readable()`. Produces a plain-English sentence or short paragraph.

**Trust-level message (first sentence):**

| Trust Score | Message |
|---|---|
| >= 80 | "Prediction can be trusted with high confidence." |
| >= 60 | "Prediction is moderately trustworthy." |
| >= 40 | "Prediction should be treated with caution." |
| < 40 | "Prediction cannot be trusted without human review." |

**Module-specific additions:**
- Routing score >= 0.8: "The routing pipeline selection was appropriate."
- Routing score < 0.5: "The routing pipeline may not have been optimal."
- Reasoning with supporting evidence > 0: "The reasoning process found {n} pieces of supporting evidence."
- Debate: "The debate involved {n} agents with {m} conflicts identified."

All sentences are joined with spaces into a single string.

## Technical Explanation

Generated by `_generate_technical()`. A pipe-delimited string of key-value pairs:

```
TrustScore=85.3 | Routing=0.85 | Reasoning=0.90 | Debate=0.80 | Memory=0.75 | Confidence=0.95
```

Only modules with non-`None` assessments are included. Each value is the raw `AuditorResult.score`.

## Module Contributions

Generated by `_compute_module_contributions()`. A dictionary mapping module name (routing, reasoning, debate, memory, confidence) to its `AuditorResult.score`. Used downstream by the `TrustEngine` to compute the `explainability_completeness` component (average of all contribution scores).

## Usage

Called from `ReflectionEngine.reflect()`:

```python
assessments_dict = {
    "routing": routing_assessment,
    "reasoning": reasoning_assessment,
    "debate": debate_assessment,
    "memory": memory_assessment,
    "confidence": confidence_assessment,
}
explainability_data = self.explainability_engine.generate(
    pipeline_context, 0.0, assessments_dict
)
```

`pipeline_context` is accepted for future enrichment (e.g., question pair details) but not currently used in explanation generation.
